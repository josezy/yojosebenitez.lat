# yojosebenitez.lat

Static resume site ready for GitHub Pages.

## Local preview

Open `index.html` in your browser, or run:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Publish with GitHub Pages

1. Create a GitHub repository named `yojosebenitez.lat` (or any name if using project pages).
2. Push this folder to the default branch.
3. In GitHub settings, enable Pages from the default branch root.
4. If using a custom domain, keep the `CNAME` file and point DNS records accordingly.
